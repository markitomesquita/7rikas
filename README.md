## Como funciona

- **Sorteio** — Um elenco histórico do São Paulo (1980–2025) cai na roleta
- **Monte seu time** — Escolha 1 jogador por sorteio, 11 no total
- **Fase de Grupos** — 3 jogos contra times clássicos da Libertadores
- **Mata-mata** — Oitavas → Quartas → Semi → Final (pênaltis em empates)
- **Ao vivo** — Placar e gols minuto a minuto, com autores
- **Card** — Gere e compartilhe sua campanha no WhatsApp

> ⚠️ Existe risco de Rafael Tolói.

## Deploy automático

O projeto usa **Vite + GitHub Actions**. A cada push na `main`, o workflow:
1. Instala as dependências
2. Roda `npm run build`
3. Publica o `dist/` no GitHub Pages automaticamente

---

## Configuração do GitHub Pages

Após subir os arquivos:

1. Vá em **Settings → Pages**
2. Em *Source*, selecione **"GitHub Actions"**
3. O primeiro deploy roda automaticamente
